# 脚本归档目录说明

本目录用于存放已经完成版本波次任务、但仍需保留追溯价值的脚本归档。

## 归档原则

- **保留证据**：用于现场排障、一次性修复、数据核验的脚本，在任务完成后可迁入此目录。
- **保持可追溯**：必要时可在归档目录中保留原始排障脚本和对应 README。
- **按版本分层**：优先使用 `archived/<version>/` 的形式归档，例如 `archived/v10_4_3/`。

## 当前归档目录

- **[v10_4_3/](v10_4_3/)**：V10.4.3 生命周期 / 系统监控 / 对账排障临时脚本

## 建议使用方式

1. 优先从 `../by_version/README.md` 找到对应版本波次。
2. 如果确认某脚本已经归档，再进入对应 `archived/<version>/README.md` 查看说明。
3. 归档脚本建议直接通过归档路径运行，例如 `python scripts/archived/v10_4_3/<script>.py`。
