# v10.3.x 脚本归纳

V10.3.x 主要集中在信号、归因、价格修复、账号维度治理与数据库补丁升级。

## 正式迁移脚本

- `../migrations/upgrade_to_v10_3.py`：V10.3 升级
- `../migrations/upgrade_to_v10_3_3.py`：V10.3.3 升级
- `../migrations/upgrade_to_v10_3_4.py`：V10.3.4 升级

## 验收 / 校验

- `../check_v10_3_2_data.py`：V10.3.2 数据验收（只读）
- `../check_attribution_data.py`：归因数据检查
- `../verify_attribution_fix.py`：归因修复验证
- `../verify_price_fix.py`：价格修复验证
- `../verify_trigger_decision_cycle.py`：触发-决策链路验证
- `../check_signal_state.py`：信号状态检查
- `../check_signals.py`：信号数据检查

## 修复 / 数据治理

- `../fix_account_id_data.py`：V10.3.3+ user_id → account_id 修复
- `../migrate_attribution_traded_at.py`：归因时间字段迁移
- `../migrate_user_id_to_account_id.sql`：账号字段重命名 SQL（与 `fix_account_id_data.py` 配套）

## 使用建议

1. 涉及数据库升级时，优先走 `migrations/`。
2. 涉及数据治理时，先看 `fix_account_id_data.py` 头部说明，再决定顺序。
3. SQL 和 Python 修复脚本配套使用时，要注意 dry-run / apply 区分。
